# Kubernetes Exam Preparation — CKA, CKAD & CKS

## 1. Vim — maîtriser l'édition YAML
S'entraîner à utiliser Vim : [Vim Trainer](https://vim-trainer.com/)

Les points clés que vous devriez pratiquer jusqu'à ce qu'ils soient automatiques :
- Sélectionner plusieurs lignes (Maj + V)
- Indenter et désindenter (> / <)
- Copier, coller, supprimer, déplacer des blocs. Ça ne prend pas longtemps à apprendre, mais vous devez le pratiquer beaucoup.

## 2. Killercoda — se familiariser avec l'environnement d'examen
[Killercoda — tarifs](https://killercoda.com/pricing)

Prendre **l'abonnement PLUS pendant un mois (9,99 $)** pour s'entraîner dans l'environnement de bureau distant utilisé pour les examens, afin de se familiariser avec le terminal Linux, le navigateur, le copier-coller et les raccourcis clavier avant le jour J.

## 3. Killer.sh — s'entraîner en conditions chronométrées
[Killer.sh](https://killer.sh/)

Utiliser les **deux simulations généralement incluses** avec l'achat d'un examen éligible CKA, CKAD ou CKS.

Killer.sh ne reproduit pas nécessairement le même environnement que l'examen officiel : son intérêt est surtout de pratiquer des exercices Kubernetes difficiles sous contrainte de temps et d'évaluer son niveau.

- **Simulation 1 :** identifier ses lacunes.
- **Simulation 2 :** mesurer ses progrès avant l'examen.

## 4. Ordre conseillé
1. Apprendre Vim et pratiquer les commandes Kubernetes.
2. S'entraîner sur Killercoda pour se familiariser avec l'environnement distant.
3. Faire la première simulation Killer.sh.
4. Corriger ses lacunes, puis faire la seconde simulation.
5. Passer l'examen officiel.
